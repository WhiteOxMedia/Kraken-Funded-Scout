🔒 Security & Transparency
What is xmrig? An open-source Monero CPU miner (MIT license). Source code: github.com/xmrig/xmrig. It's the standard mining software used by thousands of pools worldwide.

Where does it come from? The installer downloads only from the official GitHub releases page — never from a third-party mirror.

How is it verified? After download, the installer checks the SHA256 hash. If it doesn't match, the installer aborts immediately and warns you. A verify.bat script is included to re-check integrity at any time.

What does it do to my computer? Uses up to 75% of your CPU at low priority. No hidden processes. Auto-starts on Windows reboot (can be removed by deleting XMR_Jackpot_AutoStart.bat from your Startup folder). Close the window to stop mining.

Why does antivirus flag it? xmrig is sometimes flagged as "riskware" because it can be abused by malware. This is a false positive — the binary is from the official source and hash-verified. Add the folder as a Windows Defender exclusion if needed.
What the installer does:
1. Creates "XMR Jackpot Miner" folder on your Desktop
2. Downloads xmrig v6.26.0 from github.com/xmrig/xmrig/releases
3. Verifies SHA256 hash — aborts if mismatch
4. Writes config.json with your wallet + pool address
5. Creates start.bat + verify.bat for easy restarts
6. Launches the miner immediately

⚠️ Windows Defender: May block xmrig (false positive). If it does:
→ Windows Security → Virus & threat protection → Exclusions → Add folder → select "XMR Jackpot Miner" on your Desktop

Manual option: If the installer doesn't work, download xmrig manually:
→ github.com/xmrig/xmrig/releases
→ Run with: xmrig -o mine.xmrjackpot.com:3333 -u YOUR_WALLET.worker -p x
